## 一、先把软件装起来

有两种装法，**推荐第二种**（一键启动）。

### 装法 1：自己装（适合会点技术的人）

需要先装好：JDK 17+、Maven、Node.js 18+、MySQL 8+、Redis 6+。

1. **启动数据库和缓存**
   - 启动 MySQL（默认端口 3306）；
   - 启动 Redis（默认端口 6379）；
   - **不用自己建表**，软件启动时会自动建。

2. **改配置文件**
   打开 `src/main/resources/application-dev.yml`，把数据库密码改成你自己的：
   ```yaml
   cloud-ledger:
     datasource:
       password: "你的MySQL密码"   # 替换为你的 MySQL 密码
   ```

3. **启动后端**
   在项目根目录跑：
   ```bash
   mvn spring-boot:run
   ```

4. **启动前端**
   ```bash
   cd cloud-ledger-ui
   npm install
   npm run dev
   ```

5. **打开浏览器**访问 `http://localhost:5173`。

### 装法 2：一键启动（推荐）

需要先装 Docker。

1. 在项目根目录跑：
   ```bash
   docker compose up -d --build
   ```
2. 等几分钟，自动把数据库、缓存、软件都拉起来；
3. 浏览器打开 `http://localhost` 就能用。

> 给大家用的话，记得改 `docker-compose.yml` 里的数据库密码，别用弱密码。

## 二、注册并登录

### 注册
1. 打开网站首页，点"注册"；
2. 填：
   - **用户名**（1–100 字，随便起）；
   - **邮箱**（要填对，以后用它登录，只能注册一次）；
   - **密码**（8-64 位，要有字母也有数字，不能和别人一样）；
3. 点"注册"；
4. 注册成功后，系统**自动给你建好"默认账户"**（现金，余额 0）。

### 登录
1. 在登录页填邮箱和密码；
2. 点"登录"；
3. 进去后就是工作台首页。

> 登录状态保持 30 分钟，超时了重新登录就行。

### 忘了密码？重设一个
1. 在登录页点"忘记密码"；
2. 输**注册邮箱**，点"发送验证码"；
3. 去邮箱里找 **6 位数字验证码**（5 分钟内有效，别过期了）；
   - 没收到？看看垃圾邮件箱，或者等 60 秒再重发；
   - 输错 5 次验证码会作废，得重新发；
4. 输验证码 + **新密码** + **确认新密码**，点"确认重置"；
   - 新密码 8-64 位，必须有字母和数字；
   - 新密码不能和旧密码一样；
5. 重置成功，跳回登录页，用新密码登录。

> ⚠️ 重置后所有旧登录状态自动失效，得用新密码重新登。

### 登录后改密码
1. 点右上角头像 → "修改密码"；
2. 依次输入：
   - **原来的密码**；
   - **新密码**（8-64 位，有字母也有数字，不能和旧密码一样）；
   - **确认新密码**（再输一遍新密码）；
3. 点"确认"；
4. 改完后**所有登录状态自动失效**，得用新密码重新登。

## 三、管账户

### 看账户
点左边"账户"，能看到所有账户：名字、类型、现在多少钱。

### 加账户
1. 在账户页面点"新增账户"；
2. 填：
   - **账户名字**（必填，比如"建设银行储蓄卡"）；
   - **类型**（可选，默认现金）；
   - **初始余额**（可选，默认 0，不能填负数）；
3. 保存。

### 改账户
1. 找到要改的账户，点"编辑"；
2. 改名字或余额；
3. 保存。

### 删账户
1. 找到要删的账户，点"删除"；
2. 确认删除。

> ⚠️ **删账户会把里面的账单全删掉，找不回来！** 删之前想清楚。

## 四、记第一笔账

1. 点左边"账单"；
2. 点"新增账单"；
3. 一个个填：
   - **关联账户**（必填）：这笔钱从哪个账户出/进；
   - **收支类型**（必填）：收入 or 支出；
   - **分类**（必填）：从下拉里选，比如餐饮、交通、工资；
   - **金额**（必填）：大于 0，单位元，比如 `88.50`；
   - **日期**（必填）：格式 `年-月-日`，比如 `2024-01-15`；
   - **备注**（可选）：随便写点啥，比如"午餐"；
4. 点"保存"；
5. 余额自动变：
   - 记支出 → 账户钱变少；
   - 记收入 → 账户钱变多。

---

## 五、查账单

1. 在"账单"页面，上面有筛选条件：
   - **收支类型**：只看收入 or 只看支出；
   - **起始日期**、**截止日期**：格式 `年-月-日`；
2. 选好后点"查询"；
3. 账单按日期**从新到旧**排列。

---

## 六、改账单 / 删账单

### 改账单
1. 在账单列表里找到要改的，点"编辑"；
2. 改你想改的（金额、分类、日期、备注，甚至换账户都行）；
3. 保存。余额会自动调好，不用你算。

### 删账单
1. 找到要删的账单，点"删除"；
2. 确认。余额会自动把钱补回去（支出删了→钱加回来，收入删了→钱扣掉）。

---

## 七、设月度预算

1. 点左边"预算"；
2. 选月份（格式 `年-月`，比如 `2024-01`）；
3. 填预算金额（必须大于 0）；
4. 保存。同一个月再设会自动覆盖。

### 看预算花得咋样
1. 在预算页或报表页选月份；
2. 看已用百分比。超过 100% 就是超了，会提醒。

### 改预算
1. 找到那个月的预算，点"编辑"；
2. 填新金额；
3. 保存。

---

## 八、看报表

### 月度统计
1. 点左边"报表"；
2. 选月份；
3. 看到：总收入、总支出、剩多少、预算用了百分之几、每个分类花了多少。

### 趋势图
1. 在报表页切到"趋势"；
2. 可以改看几个月（默认 6 个月）；
3. 看折线图，了解收入和支出的走势。

---

## 九、用交易记录

> 想记账但**不想动账户余额**时用这个。

### 添加交易记录
1. 点"交易流水"；
2. 点"新增交易"；
3. 填：金额（必填，>0）、收支类型（必填）、分类（必填）、日期（必填，`年-月-日`）、备注（可选）；
4. 保存。**不会动账户余额。**

### 改 / 删
操作跟账单一样。但**删了不会补余额**，因为它本来就没动过余额。

---

## 十、提反馈

1. 点"反馈"；
2. 填：
   - **类型**：选 Bug 或 建议；
   - **内容**：必填，把问题或想法说清楚；
   - **联系方式**：可选，方便以后找你；
3. 提交后会给你一个编号，存好方便以后查。

> 提反馈**要先登录**，没登录提交不了。

---

## 十一、退出登录

1. 点页面右上角的"登出"；
2. 登录状态**立刻失效**，跳回登录页。

> 在公共电脑用完，**一定要退出**，别让下个人看到你的账。
